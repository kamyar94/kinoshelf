Make it play on my device

Every new file is checked against the device you watch on. A file the device would not play gets a rewrap when that loses nothing, or, if you allow it, a re-encode that must pass a quality check and come out smaller. The original is never deleted: it goes to the set-aside folder on the same drive, and each item can be put back from the week page. Details in docs/PLAYBACK.md.

Rewrap: a new container, nothing re-encoded

The new file is kept only when every picture decodes to the same image (a hash per picture, the same count), the sound decodes the same or, where a track had to become AAC, stays in step within the offset below, the lengths match, and the streams, languages and picture size are unchanged.

Re-encode: when a rewrap cannot help

H.264 with x264. The quality is measured with VMAF against the original, picture by picture. A copy that misses the gate, or that would not be smaller than the original, is thrown away and the original stays. Never larger than the original: always on.
